Setting up the files/database connection

1. Extract the ZIP file.

2. Open phpMyAdmin and create the database. Our database name is 'cointra'. Copy the provided database_schema.sql from the ZIP file, or the user can simply import the database_schema.sql file.

For Database access:
Database Name: cointra
PORT: 3306
User name: root
Password: wala pong password :3
Host name: localhost

Try the website

3. After this, the user can now open the localhost files by accessing their paths. Start with the landing.php file.

4. Create an account by clicking the Sign-up button.

5. The Forgot Password feature is included on the Log-in page for learning purposes only. Since we are running on localhost, we can't implement the OTP functionality yet, so only email validation is used.

6. Once the user enters the system, they must first add categories, accounts, and budget in chronological order to be able to add a transaction on the Transaction page.
